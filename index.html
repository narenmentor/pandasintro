Pandas Starter Guide

The very basic essentials to get started with data in Python

What is Pandas?

Pandas is a Python library that lets you load, clean, filter and summarize table data using just a few lines of code.

Think of it as Excel inside Python. Imagine a Swiggy-style orders sheet with rows and columns. Pandas lets you filter it, add totals and sort it with code, and it still works smoothly when the sheet grows to lakhs of rows.

How to use this guide

  • Every step has four parts: Concept, Explanation, Example Program and Sample Output.
  • Type each example yourself. Steps 3 onwards reuse the df table created in Step 3.
  • Your output may look slightly different on older Pandas versions (for example, text columns may show object instead of str). This is normal.

1Install and Import Pandas

Concept

Pandas is an external Python library for working with table-like data. Install it once, then import it in every program.

Explanation

  • Run pip install pandas once in your terminal.
  • import pandas as pd loads the library. pd is the short name everyone uses.

Example Program

# Run once in terminal: pip install pandas
import pandas as pd

print("Pandas is ready!")

Sample Output

Pandas is ready!

2Series: One Column of Data

Concept

A Series is a single column of values, where each value has a label (index).

Explanation

  • Create it from a list, and give your own labels with index.
  • You can run quick maths on it, like mean(), sum(), max().

Example Program

prices = pd.Series([250, 80, 300], index=["Biryani", "Dosa", "Pizza"])

print(prices)
print("Average price:", prices.mean())

Sample Output

Biryani    250
Dosa        80
Pizza      300
dtype: int64
Average price: 210.0

3DataFrame: A Full Table

Concept

A DataFrame is a table with rows and columns, just like an Excel sheet. It is the main object you will use in Pandas.

Explanation

  • Build it from a dictionary: each key becomes a column name, each list becomes the column's values.
  • The numbers on the left (0, 1, 2...) are the row index. Pandas adds them for you.

Example Program

df = pd.DataFrame({
    "Item":  ["Biryani", "Dosa", "Pizza", "Burger", "Idli"],
    "Price": [250, 80, 300, 150, 40],
    "Qty":   [2, 3, 1, 2, 4],
    "City":  ["Chennai", "Madurai", "Chennai", "Salem", "Madurai"]
})

print(df)

Sample Output

      Item  Price  Qty     City
0  Biryani    250    2  Chennai
1     Dosa     80    3  Madurai
2    Pizza    300    1  Chennai
3   Burger    150    2    Salem
4     Idli     40    4  Madurai

4Save and Read a CSV File

Concept

Real data usually lives in CSV files. Pandas can save a DataFrame to CSV and read it back in one line.

Explanation

  • to_csv() saves the table. index=False skips the row numbers.
  • read_csv() loads a CSV file into a DataFrame.
  • head(3) shows only the first 3 rows. Great for a quick peek.

Example Program

df.to_csv("orders.csv", index=False)

data = pd.read_csv("orders.csv")
print(data.head(3))

Sample Output

      Item  Price  Qty     City
0  Biryani    250    2  Chennai
1     Dosa     80    3  Madurai
2    Pizza    300    1  Chennai

5Explore Your Data

Concept

Before any analysis, check the size, column types and basic statistics of your data.

Explanation

  • shape gives (rows, columns).
  • columns lists all the column names.
  • describe() gives count, mean, min, max and more for number columns.

print(df.shape)
print(df.columns.tolist())

print(df.describe())

6Select Columns and Rows

Concept

Pick exactly the part of the table you need: one column, a few columns, or one row.

Explanation

  • df["Item"] gives one column.
  • df[["Item", "Price"]] (double brackets) gives several columns.
  • df.iloc[0] gives a row by its position number.

Example Program

print(df["Item"].head(3))
print()
print(df[["Item", "Price"]].head(3))
print()
print(df.iloc[0])

7Filter Rows with a Condition

Concept

Filtering keeps only the rows that match a condition, like the Filter option in Excel.

Explanation

  • df["Price"] > 100 checks every row and gives True or False.
  • Putting that inside df[ ... ] keeps only the True rows.
  • Use == to match text, and & to combine two conditions.

Example Program

expensive = df[df["Price"] > 100]
print(expensive)
print()

chennai = df[df["City"] == "Chennai"]
print(chennai)

Sample Output

      Item  Price  Qty     City
0  Biryani    250    2  Chennai
2    Pizza    300    1  Chennai
3   Burger    150    2    Salem

      Item  Price  Qty     City
0  Biryani    250    2  Chennai
2    Pizza    300    1  Chennai

8Add a New Column

Concept

You can create a new column by doing maths on existing columns. Pandas applies it to every row at once.

Explanation

  • Assign to a new column name with =.
  • No loop needed. Pandas handles all rows together.

Example Program

df["Total"] = df["Price"] * df["Qty"]
print(df)

Sample Output

      Item  Price  Qty     City  Total
0  Biryani    250    2  Chennai    500
1     Dosa     80    3  Madurai    240
2    Pizza    300    1  Chennai    300
3   Burger    150    2    Salem    300
4     Idli     40    4  Madurai    160

9Sort the Data

Concept

Sorting arranges rows by the values of a column, from small to large or the other way round.

Explanation

  • sort_values() takes the column name to sort by.
  • ascending=False sorts from highest to lowest.

Example Program

top_orders = df.sort_values("Total", ascending=False)
print(top_orders)

Sample Output

      Item  Price  Qty     City  Total
0  Biryani    250    2  Chennai    500
2    Pizza    300    1  Chennai    300
3   Burger    150    2    Salem    300
1     Dosa     80    3  Madurai    240
4     Idli     40    4  Madurai    160

10Handle Missing Values

Concept

Real data often has empty cells, shown as NaN (Not a Number). You should find them and fix them.

Explanation

  • isnull().sum() counts the empty cells in each column.
  • fillna() replaces empty cells with a value of your choice, here the average.
  • dropna() is the other option. It removes rows that have empty cells.

Example Program

marks = pd.DataFrame({
    "Name":  ["Anu", "Ravi", "Divya"],
    "Score": [85, None, 92]
})

print(marks.isnull().sum())
print()

marks["Score"] = marks["Score"].fillna(marks["Score"].mean())
print(marks)

Sample Output

Name     0
Score    1
dtype: int64

    Name  Score
0    Anu   85.0
1   Ravi   88.5
2  Divya   92.0

11Group and Summarize

Concept

groupby() splits the data into groups, then calculates a summary for each group. It is like a Pivot Table in Excel.

Explanation

  • groupby("City") makes one group per city.
  • ["Total"].sum() adds up the Total column inside each group.
  • You can also use mean(), count(), max() and min().

Example Program

city_sales = df.groupby("City")["Total"].sum()
print(city_sales)

Sample Output

City
Chennai    800
Madurai    400
Salem      300
Name: Total, dtype: int64

Try It Yourself

The best way to learn Pandas is to practice on your own small table.

  • Create a DataFrame of 5 students with Name, Marks and City.
  • Filter the students who scored above 80, then sort them by Marks.
  • Add a Grade column, then find the average Marks for each City using groupby.
